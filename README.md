# NYC Budget Allocation Recommendation System

**NYC Budget Allocation Recommendation System: Predicting Agency Funding Needs Using Data Analytics and Machine Learning**

---

# Overview

New York City allocates billions of dollars each year to government agencies through its budgeting process. However, the amount initially adopted often differs from the modified budget and the actual expenditures due to changing priorities, emergency funding, and fluctuations in service demand.

This project analyzes historical NYC budget data to understand how agencies use their allocated funds, identify spending patterns and funding gaps, and evaluate budget efficiency. By incorporating machine learning models and additional socioeconomic indicators, the project aims to predict future agency budget needs and recommend more effective budget allocations.

The final deliverables include an interactive Tableau dashboard, predictive machine learning models, and a budget recommendation system that provides data-driven insights for improving future budget planning.

---

# Problem Statement

Government budgeting is a complex process that often relies on historical spending patterns and manual decision-making. As city priorities, population, and public service demands change, accurately allocating resources becomes increasingly difficult.

Many agencies receive budget modifications throughout the fiscal year, making it challenging to determine whether the original budget was sufficient or whether resources could have been allocated more efficiently. There is currently a lack of predictive, data-driven tools that help policymakers anticipate future funding needs and optimize budget distribution.

This project addresses that gap by analyzing historical budget performance and using machine learning to forecast future funding requirements and prioritize agency funding.

---

# Objectives

The objectives of this project are to:

- Compare adopted budgets, modified budgets, and actual expenditures across NYC agencies.
- Analyze agency spending patterns and identify funding gaps.
- Measure budget efficiency using historical financial data.
- Predict future budget requirements using regression models.
- Classify agencies based on funding priority and resource utilization.
- Develop an interactive dashboard for budget analysis and visualization.
- Build a budget recommendation system to support data-driven decision making.

---

# Research Questions

This project seeks to answer the following questions:

1. How do adopted budgets compare to modified budgets and actual expenditures?
2. Which agencies consistently exceed or underspend their allocated budgets?
3. Which agencies demonstrate the highest budget efficiency?
4. Can historical budget data accurately predict future funding needs?
5. Which agencies should receive priority funding in future budget cycles?

# Solution

This project develops a data-driven budget recommendation system that combines exploratory data analysis, machine learning, and interactive visualization.

The system will:

- Visualize spending and budget performance through an interactive Tableau dashboard.
